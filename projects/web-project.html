Web Design & Development

Website Redesign Project

A responsive website designed and developed with a focus on usability, visual design, and creating a clear user experience.

Overview

This project involved designing and developing a responsive website from the initial concept through implementation. The goal was to create a visually engaging website while maintaining a simple and intuitive user experience.

Role

UI/UX Designer & Developer

Tools

Figma, HTML, CSS, JavaScript

Focus

Web Design & Front-End Development

The Problem

The challenge was to create a website that presented information clearly while maintaining a cohesive visual identity. The interface needed to be easy to navigate and work effectively across different screen sizes.

Design Goals

  • Create a clear and intuitive navigation system.
  • Establish a consistent visual hierarchy.
  • Create a responsive layout for different screen sizes.
  • Use typography, spacing, and color intentionally.
  • Create an engaging but easy-to-use interface.

Wireframes

I began by creating wireframes to establish the overall structure and hierarchy of the website before focusing on visual details.

Visual Design

After establishing the structure, I developed the visual design in Figma. I focused on creating a consistent design system using typography, color, spacing, and reusable components.

Development

After completing the design, I translated the interface into a functional website using HTML, CSS, and JavaScript.

HTML was used to create the structure of the website, CSS was used to control the visual presentation and responsive layout, and JavaScript was used to add interactive behavior.

Responsive Design

I designed the layout to adapt to different screen sizes so that the experience remains usable on desktop, tablet, and mobile devices.

Interaction & Animation

JavaScript and CSS were used to introduce interactive elements and subtle animations. These interactions were designed to provide visual feedback without distracting from the content.

Testing & Iteration

I tested the website throughout the development process to identify usability issues, layout problems, and areas that could be improved.

Based on the results, I refined the layout, navigation, spacing, and interactions to create a clearer overall experience.

Final Design

The final website combines the original visual direction with the improvements made during development and testing.

What I Learned

This project helped me strengthen my understanding of the relationship between design and development. I learned how design decisions made in Figma translate into HTML and CSS and how small implementation details can affect the overall user experience.

I also gained more experience thinking about responsive design, accessibility, interaction, and usability throughout the development process.
